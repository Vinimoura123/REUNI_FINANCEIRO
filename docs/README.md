# 📁 Documentos do Evento REUNI (BI - UFBA)

Esta pasta é o repositório central de informações e documentos oficiais da **Reunião Unificada dos Bacharelados Interdisciplinares da UFBA (REUNI)**.

Todos os arquivos colocados aqui serão analisados pelo agente para fundamentar:
1. **Concepção da Arte Conceitual & Identidade Visual** (Logotipos, temas, cores, tipografia).
2. **Arquitetura de Dados & Estrutura do Sistema Financeiro** (Fluxo de caixa, categorias de receita/despesa, prestação de contas, orçamentos, inscrições).
3. **Regras de Negócio & Telas do App** (Dashboard, relatórios, gestão de comissões).

---

## 📂 Organização das Subpastas

- **`docs/evento/`**: Editais, regulamentos, atas, cronograma e programação geral.
- **`docs/financeiro/`**: Planilhas prévias, balancetes, categorias de receitas/despesas e orçamentos.
- **`docs/identidade_visual/`**: Referências visuais, artes prévias, cores e marca REUNI / BI UFBA.
